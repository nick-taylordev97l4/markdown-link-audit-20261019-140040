## Overview

This repository provides a neutral reference for Markdown link syntax. It demonstrates how to link to external resources, navigate within a document, and create persistent anchors for headings.

## Absolute URLs

Use for external resources. Always include a protocol.

```
https://example.com/article
```

## Relative Links

Use for navigation within the repository or related files.

```
./files/guide.md
../other-repo/readme.md
```

## Heading Anchors

Use `#` followed by a lowercase slug to link to headings. Slugs must match the heading text exactly.

```
# My Heading

[Link](#my-heading)
```
